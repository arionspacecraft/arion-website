# ARION website ownership

- The website repository is `https://github.com/arionspacecraft/arion-website`.
- Deploy only to `https://arionspacecraft.github.io/arion-website/` unless the user requests a different destination.
- Use a GitHub connection authenticated as `arionspacecraft` for remote writes. Verify the authenticated account before writing; do not fall back to a personal account session.
- The main branch deploys automatically through GitHub Actions. Validate changes before publishing.
- Read [HANDOFF.md](HANDOFF.md) before continuing after a folder move or in a new session. Repository identity, not an old absolute folder path, determines the correct checkout.
- Light and dark themes are approved for production as of 2026-10-18. Production follows the device setting automatically; manual theme controls are for development only.
- Preserve existing files and local changes. Ask before deleting or relocating user files. Update the existing Obsidian note `ARION 홈페이지 운영과 노션 연동` when work is complete; do not create a duplicate note merely because the vault moved.
